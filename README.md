## More experiments

- **[Chess Bot](https://github.com/enricpedrico/chess_bot)** — A chess engine in Python, with FEN parsing, move generation and position evaluation.
- **[TFG](https://github.com/enricpedrico/TFG)** — Optimization models in MiniZinc, test case generation in Python and solver comparisons.

## Tools across these projects

**Web:** TypeScript, JavaScript, React and Node.js.<br>
**Engines & models:** Rust, C++, WebAssembly, Python and MiniZinc.<br>
**Data & deployment:** SQLite, Docker and Caddy.
